# Политика подписи кода

Документ описывает, кто и как подписывает сборки Vacate. Он требуется программой
бесплатной подписи для проектов с открытым исходным кодом и заодно отвечает
на разумный вопрос пользователя: почему этой программе можно доверять.

Он же является автором кода, рецензентом изменений и лицом, утверждающим подпись

По мере появления участников роли будут разделены и этот раздел обновлён.

## Что подписывается

Подписываются только сборки, собранные из исходного кода этого репозитория:

- `Vacate.exe` — графическое приложение
- `vacate-cli.exe` — консольная версия
- установщик

Сборки собираются скриптом `packaging/build.ps1` из состояния репозитория,
соответствующего метке выпуска. Посторонние двоичные файлы в поставку не входят.

## Приватность пользователей

Программа работает полностью на компьютере пользователя.

- **Никакие данные никуда не передаются.** Ни статистика использования, ни сведения
  о системе, ни содержимое найденных файлов
- Единственное сетевое обращение — проверка наличия новой версии на GitHub.
  Она выполняется не чаще раза в сутки и **полностью отключается** в настройках
- Журнал работы и карантин хранятся локально, в папке пользователя
- Отчёт об ошибке сохраняется в файл на компьютере и **никуда не отправляется
  автоматически**. Из него убираются имя пользователя и путь к его профилю,
  потому что такой файл человек может переслать

## Удаление программы

Программа удаляется штатно через «Параметры → Приложения» или файлом `unins000.exe`
в папке установки. При удалении:

- убирается задача автоматической очистки из планировщика — иначе система
  еженедельно запускала бы несуществующий файл
- если в карантине остались файлы пользователя, установщик **спрашивает** перед их
  удалением, а не стирает молча

Переносимая версия удаляется удалением папки.

## Границы, которые программа не переступает

Заявлены не как обещание, а как проверяемое свойство кода:

- Не отключает Windows Defender, UAC и настройки безопасности
- Не трогает каталог `System32`, загрузчик и драйверы
- Критичные системные службы доступны только для просмотра
- Не использует драйверы режима ядра
- Графический интерфейс работает **без прав администратора**; операции, которым права
  действительно нужны, выполняет отдельный процесс с обычным запросом системы

## Средство подписи

Планируется подпись через SignPath Foundation — бесплатную программу подписи кода
для проектов с открытым исходным кодом: https://signpath.org

До её получения сборки распространяются неподписанными, о чём прямо сказано
на странице загрузки и в описании выпуска.
